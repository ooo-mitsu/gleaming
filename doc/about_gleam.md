# Gleam言語

## 概要

- イギリスの Louis Pilfold 氏が開発しました。
- 「シンプルさ」「親切さ」「安全さ」を重視して設計された静的型付けの関数型プログラミング言語です。
  - シンプルさ
    - 馴染みやすい構文
      - 関数型ですが、JavaScript,Rust,Goなどの見慣れたモダンな構文を採用しています。
    - 小さな言語仕様
      - if 文や for ループがありません。代わりにパターンマッチン(case式)や再帰を使って記述します。

  - 親切さ
    - 親切なコンパイラ
      - Rustに影響を受けた親切なエラーメッセージを出力します。
  - 安全さ
    - 静的型システムとコンパイル時の強力な分析で実行時の予期せぬクラッシュを最小限に抑えてくれます。
    - Nullや例外はなく、Option型やResult型を用いて値の不在や失敗を明示的に扱い、実行時のクラッシュを防ぎます。
- Erlang仮想マシン(BEAM)およびJavaScriptランタイムで動作します。
  - 同一の言語でバックエンドからフロントエンド(ブラウザ,Node.jsなど)まで開発でき、コードの共有も可能です

## インストール

[Installing Gleam](https://gleam.run/install/)に、各OS のインストール方法が記載されています。

私は、WSL2(Ubuntu)で、まずは、erlang-base のインストールを行いました。

```bash
sudo apt install erlang-base
```

そのあとに、gleam をインストールしました。

```bash
wget https://github.com/gleam-lang/gleam/releases/download/v1.16.0/gleam-v1.16.0-x86_64-unknown-linux-musl.tar.gz
wget https://github.com/gleam-lang/gleam/releases/download/v1.16.0/gleam-v1.16.0-x86_64-unknown-linux-musl.tar.gz.sha512
sha512sum -c gleam-v1.16.0-x86_64-unknown-linux-musl.tar.gz.sha512
tar xvf gleam-v1.16.0-x86_64-unknown-linux-musl.tar.gz
chmod 755 gleam
mkdir ~/.local/bin
mv gleam ~/.local/bin/
source ~/.bashrc
gleam --version
```

PATH が通っていない場合は、`~/.bashrc` に下記を追加する必要があります。
```bash
export PATH=$PATH:$HOME/.local/bin
```

`~/.bashrc`追記後に、`source ~/.bashrc` で、gleam が実行できるようになっているハズです。

また、VS Code の拡張機能「Gleam」もインストールしました。

## コメント

| 種類                                   | 記法   | 用途                                                                     |
| :------------------------------------- | :----- | :----------------------------------------------------------------------- |
| **通常のコメント**                     | `//`   | 一般的なコードの説明やメモ用                                             |
| **ドキュメントコメント(アイテム用)**   | `///`  | 型や関数の定義の直前に記述し、そのアイテムのドキュメントとして機能します |
| **ドキュメントコメント(モジュール用)** | `////` | モジュールの先頭に記述し、モジュール全体の説明に使用されます             |

### コメントのルール

- **行コメントのみ:** 複数行コメント(ブロックコメント)の構文はありません。
- **配置場所:** コメントは、対象とするコードの**前の行**に記述します。コードと同じ行の末尾(行末コメント)に記述した場合、コードフォーマッタによって自動的に次の行へ移動されます。
- **ドキュメント生成:** `///` や `////` で記述された内容は、ツールを使用してドキュメントを生成する際に反映されます。

```gleam
//// モジュールの説明

/// typeの説明
pub type Never {
  Never(Never)
}

// 通常のコメント

/// fnの説明
pub fn twice(argument: value, my_function: fn(value) -> value) -> value {
  // 通常のコメント
  my_function(my_function(argument))    // 通常のコメント(コードフォーマッタを通すと下行へ移動してしまうので注意)
}
```

## 型

| 分類             | 型名             | 概要                                                     | 例                                |
| :--------------- | :--------------- | :------------------------------------------------------- | :-------------------------------- |
| **基本型**       | **Int**          | 整数型。アンダースコアでの区切りや、16進数等の表記も可能 | `1`, `-5`, `1_000_000`, `0x1A`    |
|                  | **Float**        | 浮動小数点数型。指数表記もサポート                       | `3.14`, `1.0`, `6.022e23`         |
|                  | **String**       | UTF-8エンコードされた文字列。複数行も可能                | `"Hello"`, `"Gleam⭐"`           |
|                  | **Bool**         | 真偽値                                                   | `True`, `False`                   |
|                  | **Nil**          | 「値がない」ことを表すユニット型 (Nullとは異なる)        | `Nil`                             |
| **コレクション** | **List**         | 同一型の値を保持する連結リスト                           | `["a", "b"]`                      |
|                  | **Tuple**        | 異なる型を混在できる固定サイズの集合                     | `#(1, "hi")`, `#(3.14, True)`     |
|                  | **Dict(k, v)**   | キーと値のペア。標準ライブラリ(gleam/dict)を使用して作成 | `dict.from_list([#("a", 1)])`     |
|                  | **BitArray**     | バイナリデータ(ビットの並び)                             | `<<255, 0, 100>>`, `<<"A":utf8>>` |
| **特殊型**       | **Result(a, e)** | 成功(Ok)または失敗(Error)を表す型                        | `Ok(200)`, `Error("Not Found")`   |
|                  | **Option(a)**    | 値の存在(Some)または不在(None)を表す型                   | `Some(42)`, `None`                |
|                  | **Dynamic**      | 外部から入る型不明のデータ。デコードして使用             | `dynamic.from(123)`               |
| **ユーザー定義** | **Custom Type**  | `type`キーワードで定義する独自の列挙型                   | `type Status { Online Offline }`  |
|                  | **Record**       | カスタム型のバリアントにデータを持たせたもの             | `User(id: 1, name: "Joe")`        |

### 型の補足

- **厳格な区別:** `Int`と`Float`は厳密に区別されます。例えば、整数には`+`、浮動小数点数には`+.`というように、使用する演算子も異なります。
- **イミュータブル(不変):** 上表にあるすべてのデータ型は不変です。一度作成した値を書き換えることはできず、変更が必要な場合は新しい値を作成(あるいはレコードアップデート構文を使用)します。
- **型推論:** Gleamは強力な型推論を持つため、多くの場合で`let x = 1`のように型を省略できますが、`let x: Int = 1`のように明示的に注釈を付けることも可能です。
- **カスタム型の柔軟性:** カスタム型は単一のバリアント(構造体のような使い方)から、複数のバリアント(列挙型のような使い方)まで幅広く定義でき、パターンマッチングと組み合わせて強力な制御フローを構築できます。
  - 複数バリアント(列挙型的)
    ```gleam
    pub type Status {
      Online
      Offline
      Away
    }
    ```
  - 複数バリアント(レコード, 共用体的)
    ```gleam
    pub type SchoolPerson {
      Teacher(name: String, subject: String)
      Student(name: String, age: Int)
    }
    ```
  - 単一バリアント(レコード, 構造体的)
    ```gleam
    pub type User {
      User(id: Int, name: String, email: String)
    }
    ```

## 演算子

| 分類                   | 演算子                   | 説明                                                                        | 例                         |
| :--------------------- | :----------------------- | :-------------------------------------------------------------------------- | :------------------------- |
| **算術 (整数: Int)**   | `+`, `-`, `*`            | 整数同士の加算、減算、乗算。                                                | `1 + 2 → 3`               |
|                        | `/`                      | 整数同士の除算。**0で割ると 0** を返します。                                | `5 / 2 → 2`, `5 / 0 → 0` |
|                        | `%`                      | 整数同士の剰余(余り)。                                                      | `5 % 2 → 1`               |
| **算術 (小数: Float)** | `+.`, `-.`, `*.`         | 小数同士の加算、減算、乗算。小数専用の演算子が必要です。                    | `1.0 +. 2.0 → 3.0`        |
|                        | `/.`                     | 小数同士の除算。整数同様、**0で割ると 0.0** を返します。                    | `3.0 /. 2.0 → 1.5`        |
| **比較 (共通)**        | `==`, `!=`               | 構造的な等価および不等価。両辺が同じ型である必要があります。                | `1 == 1 → True`           |
| **比較 (整数)**        | `>`, `<`, `>=`, `<=`     | 整数同士の大小比較。                                                        | `5 > 2 → True`            |
| **比較 (小数)**        | `>.`, `<.`, `>=.`, `<=.` | 小数同士の大小比較。                                                        | `3.14 >. 2.0 → True`      |
| **論理 (Bool)**        | `&&`, `\|\|`             | 論理積 (AND) と論理和 (OR)。**短絡評価**(左辺で確定すれば右辺は評価ません)  | `True && False → False`   |
|                        | `!`                      | 論理否定 (NOT)。                                                            | `!True → False`           |
| **文字列**             | `<>`                     | 文字列の連結。パターンマッチでの接頭辞判定にも使えます。                    | `"Gl" <> "eam" → "Gleam"` |
| **特殊演算子**         | `\|>`                    | **パイプライン演算子**。左辺の結果を右辺の関数の第1引数に渡します。         | `x \|> func()`             |
|                        | `<-`                     | `use` 式で使用され、コールバック関数を平坦に記述するために用います。        | `use x <- func()`          |
|                        | `..`                     | **スプレッド/更新演算子**。リストの残り要素の抽出やレコードの更新に使います | `[1, ..rest]`              |
|                        | `.`                      | レコードのフィールドやタプルの要素(`.0`等)へのアクセス                      | `user.name`, `tuple.0`     |
|                        | `#(...)`                 | **タプル**の作成構文。                                                      | `#(1, "hi")`               |
|                        | `{...}`                  | **ブロック(式のグループ化)**。算術演算の優先順位変更にも使用します          | `{ 1 + 2 } * 3 → 9`       |
|                        | `_`                      | **破棄パターン**。値を使用しないことを明示する際に変数名の前に付けます      | `let _ = 10`               |
|                        | `->`                     | `case` 式のパターンと処理の区切り、または関数の戻り値型の指定               | `_ -> "Error"`             |

---

### 他言語との差異
- **IntとFloatの厳格な区別**: Gleamには演算子のオーバーロードがないため、整数(`+`)と小数(`+.`)で演算子を使い分ける必要があります。
- **型変換の不在**: 整数と小数の間で暗黙の型変換は行われません,。整数と小数を計算したい場合は、明示的に型変換を行う必要があります。
- **0除算の仕様**: 実行時のクラッシュを避けるため、整数および小数の除算において、**0で割った結果は 0** と定義されています。より厳密な処理が必要な場合は、標準ライブラリの `result` を返す関数を使用します。
- **パイプラインの可読性**: `|>` を使うことで、内側から外側へ読む入れ子状の関数呼び出しを、上から下への直感的な流れに書き換えられます。
- **グループ化**: 算術演算の優先順位を変更する場合、丸括弧 `()` ではなく、**波括弧 `{}`** (ブロック)を使用します,。
  - 例: `{ 1 + 2 } * 3 → 9`

## 関数内の文・式

| 処理           | 項目                     | 概要                                                   | 記述例                                                   |
| :------------- | :----------------------- | :----------------------------------------------------- | :------------------------------------------------------- |
| **変数束縛**   | **`let`**                | 変数に値を割り当てます。不変(Immutable)です。          | `let score = 10`                                         |
| **ブロック**   | **`{ }`**                | 複数の式をまとめ、最後の式の結果を返します。           | `{ let a = 1; a + 2 } // 3を返す`                        |
| **条件分岐**   | **`case`**               | パターンマッチングによる分岐。値を返します。           | `case x { 1 -> "One"  _ -> "Other" }`                    |
| **反復処理**   | **再帰**                 | ループの代わりに自分自身を呼び出します。               | `fn loop(n) { case n { 0 -> 0  _ -> n + loop(n - 1) } }` |
| **安全な中断** | **`let assert`**         | 特定のパターンのみを期待し、失敗ならパニックさせます。 | `let assert Ok(user) = get_user()`                       |
| **開発支援**   | **`todo`**               | 未実装箇所をマークします(警告が出ます)。               | `todo as "後で実装する"`                                 |
|                | **`panic`**              | 到達不能な箇所で強制終了させます。                     | `_ -> panic as "ありえない状態"`                         |
|                | **`echo`**               | 値をプリントしつつ、その値をそのまま返します。         | `x \|> echo \|> int.to_string`                           |
| **合成**       | **パイプライン (`\|>`)** | 左の結果を次の関数の第1引数に渡します。                | `"hello" \|> string.reverse`                             |
| **高度な制御** | **`use`**                | コールバックを平坦に記述します。                       | `use val <- result.try(my_func())`                       |

### `let` 文

| 用途                   | 説明                                                                       | 記述例                                       |
| :--------------------- | :------------------------------------------------------------------------- | :------------------------------------------- |
| **基本的な代入**       | 変数に値を割り当てます。変数名はスネークケースで記述します。               | `let score = 10`                             |
| **型アノテーション**   | 明示的に型を指定する場合に使用します(通常は推論されます)。                 | `let x: Int = 5`                             |
| **シャドウイング**     | 同じ変数名で新しい値を束縛し直します。元の値は変更されません。             | `let x = 1`<br>`let x = x + 1 // xは2になる` |
| **未使用変数の処理**   | 値を使用しない場合は、名前を `_` で始めて警告を抑制します。                | `let _unused = "data"`                       |
| **タプルの分解**       | タプルの内容を複数の変数に一度に展開して束縛します。                       | `let #(a, b) = #(1, 2)`                      |
| **レコードの分解**     | カスタム型(レコード)から特定のフィールドを抽出します。                     | `let User(name, ..) = user`                  |
| **部分的なマッチング** | マッチしない場合にパニック(強制終了)させるアサーションとして機能します。   | `let assert Ok(val) = res`                   |

### case式とパターンマッチング

| 項目                 | 内容                                                                                               | 記述例                                    |
| :------------------- | :------------------------------------------------------------------------------------------------- | :---------------------------------------- |
| **case式**           | 式(Expression)として評価され、一致したパターンの**最後の値**を返します。                           | `case x { 1 -> "one" _ -> "other" }`      |
| **網羅性チェック**   | コンパイラが、**全ての可能性が網羅されているか**を厳格に確認します。漏れがあるとエラーになります。 | 全てをカバーするか、`_` を使用します。    |
| **変数パターン**     | 一致した値に名前を付け、その値を処理内で利用できます。                                             | `x -> x + 1`                              |
| **破棄パターン**     | 使用しない値はアンダースコア `_` で無視できます。                                                  | `_ -> "ignore"`                           |
| **文字列パターン**   | **`<>` 演算子**を用いて、特定の接頭辞を持つ文字列にマッチさせることができます。                    | `"Hello, " <> name -> name`               |
| **リストパターン**   | 空リスト `[]` や、先頭要素と残りのリスト `[head, ..tail]` を分解できます。                         | `[1, ..rest]` (1で始まるリスト)         |
| **タプル/レコード**  | データの構造を分解して、内部のフィールド値を取り出せます。                                         | `#(a, b) -> a` / `User(name, ..) -> name` |

| **`lazy_or`** | 1つ目が `None` の場合のみ、関数を実行して得られた代替の `Option` を返します。 | `option.lazy_or(None, fn() { Some(1) }) // Some(1)` |
| **`lazy_unwrap`** | 値を取り出します。`None` の場合は、関数を実行して得られたデフォルト値を返します。 | `option.lazy_unwrap(None, fn() { 0 }) // 0` |
| **`map`** | `Some` の中の値に関数を適用します。`None` の場合は何もせず `None` を返します。 | `option.map(Some(2), fn(x) { x * 2 }) // Some(4)` |
| **`or`** | 1つ目が `Some` ならそれを返し、`None` なら2つ目の `Option` を返します。 | `option.or(None, Some(1)) // Some(1)` |
| **`then`** | `Some` の中の値に `Option` を返す関数を適用し、結果を平坦化します(`map` して `flatten` するのと同等)。 | `option.then(Some(1), fn(x) { Some(x + 1) }) // Some(2)` |
| **`to_result`** | `Option` を `Result` 型に変換します。`None` の際のエラー値を指定します。 | `option.to_result(Some(1), "Error") // Ok(1)` |
| **`unwrap`** | `Some` から値を取り出します。`None` の場合は指定したデフォルト値を返します。 | `option.unwrap(Some(1), 0) // 1` |
| **`values`** | `Option` のリストから `Some` の値だけを抽出してリストとして返します。 | `option.values([Some(1), None, Some(2)]) //` |

### `gleam/result` モジュール

| 関数名 | 概要 | 使用例 |
| :--- | :--- | :--- |
| **`all`** | リスト内のすべての結果が `Ok` なら `Ok(List)` を、一つでも `Error` なら最初のエラーを返します。 | `result.all([Ok(1), Ok(2)]) // Ok()` |
| **`flatten`** | 二重にラップされた結果(`Result(Result(a, e), e)`)を一段階に平坦化します。 | `result.flatten(Ok(Ok(1))) // Ok(1)` |
| **`is_error`** | 結果が `Error` であるかどうかを判定します。 | `result.is_error(Error(Nil)) // True` |
| **`is_ok`** | 結果が `Ok` であるかどうかを判定します。 | `result.is_ok(Ok(1)) // True` |
| **`lazy_or`** | `Error` の場合、関数を実行して得られた代替の `Result` を返します。 | `result.lazy_or(Error(1), fn() { Ok(2) })` |
| **`lazy_unwrap`** | `Ok` から値を取り出します。`Error` の場合は関数を実行してデフォルト値を生成します。 | `result.lazy_unwrap(Error(1), fn() { 0 }) // 0` |
| **`map`** | `Ok` の中の値に関数を適用します。`Error` の場合は何もせずそのまま返します。 | `result.map(Ok(1), fn(x) { x + 1 }) // Ok(2)` |
| **`map_error`** | `Error` の中の値に関数を適用します。`Ok` の場合は何もせずそのまま返します。 | `result.map_error(Error(1), fn(x) { x + 1 })` |
| **`or`** | 1つ目が `Ok` ならそれを返し、`Error` なら2つ目の `Result` を返します。 | `result.or(Error(1), Ok(2)) // Ok(2)` |
| **`partition`** | 結果のリストを「成功値のリスト」と「エラー値のリスト」のペアに分割します。 | `result.partition([Ok(1), Error(2)]) // #(,)` |
| **`replace`** | `Ok` の中の値を、指定した新しい値で置き換えます。 | `result.replace(Ok(1), 2) // Ok(2)` |
| **`replace_error`** | `Error` の中の値を、指定した新しいエラー値で置き換えます。 | `result.replace_error(Error(1), 2) // Error(2)` |
| **`try`** | `Ok` の値に「結果を返す関数」を適用し、結果を平坦化します。関数の連鎖に便利です。 | `result.try(Ok(1), fn(x) { Ok(x + 1) }) // Ok(2)` |
| **`try_recover`** | `Error` の値に「結果を返す関数」を適用し、エラーからの復旧を試みます。 | `result.try_recover(Error(e), fn(e) { Ok(1) })` |
| **`unwrap`** | `Ok` から値を取り出します。`Error` の場合は指定したデフォルト値を返します。 | `result.unwrap(Ok(1), 0) // 1` |
| **`unwrap_error`** | `Error` からエラー値を取り出します。`Ok` の場合はデフォルト値を返します。 | `result.unwrap_error(Error(1), 0) // 1` |
| **`values`** | リストの中から `Ok` の値だけを抽出してリストとして返します。 | `result.values([Ok(1), Error(2)]) //` |
